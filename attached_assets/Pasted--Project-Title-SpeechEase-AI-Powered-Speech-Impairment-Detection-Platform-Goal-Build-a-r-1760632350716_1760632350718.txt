🎯 Project Title:

“SpeechEase: AI-Powered Speech Impairment Detection Platform”

🧩 Goal

Build a responsive web application that allows therapy centers to:

Record patients reading sentences aloud

Analyze their speech using AI

Classify results into one of six speech disorder classes

Display motivational, gamified feedback

Auto-generate a professional health report for the therapist

🧱 Core System Architecture

Frontend: React + TailwindCSS (Next.js optional)

Backend: Node.js (Express) or Python Flask

Database: Firebase Firestore or MongoDB

Storage: Firebase Storage / AWS S3 (for voice files)

Authentication: Firebase Auth / JWT-based login

AI Integration:

Speech-to-text: OpenAI Whisper API (or Google Cloud Speech)

Feature extraction & classification: Custom ML model (TensorFlow / PyTorch)

Text summarization: GPT API (for health summary generation)

PDF Report: jsPDF / ReportLab

Email Service: SendGrid / Nodemailer

👤 User Roles
1. Patient/User

🗣️ Speech Analysis Pipeline

Record Audio

Capture user voice with browser microphone API (MediaRecorder).

Save each sentence as separate .wav or .mp3.

Speech-to-Text (STT)

Use OpenAI Whisper API or Google Cloud STT.

Compare transcribed sentence with original.

Feature Extraction (ML Model Input)

Extract MFCCs, formants, pitch contour, and phoneme durations.

Normalize and vectorize for model inference.

Classification (6 Classes)
Model predicts one of:

Phonological Impairment

Vowel Disorder

Childhood Apraxia of Speech

Inconsistent Phonological Impairment

Articulation Disorder

Cleft Palate
(Optional seventh class: Normal Speech)

Output → { label, confidence_score, key_features }

Motivational Feedback Generation

Use GPT API to create two short encouraging bullet points.

Example prompt:

“Generate two positive and empathetic feedback lines for a patient diagnosed with {{label}}, age {{age}}. Keep tone cheerful and supportive.”

Report Generation

Combine:

User info

Classification result

Confidence score

AI observations

GPT-generated professional health summary

Convert to PDF

Email to therapist automatically.
